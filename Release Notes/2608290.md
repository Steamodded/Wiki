# 26.829.0

This release sees a change in how we version the API, due to updating our Thunderstore upload (you can find that [here](https://thunderstore.io/c/balatro/p/Steamodded/Steamodded/)).

We also have a new and improved wiki site, which has documentation for a lot of these new additions, with more to come as they are completed. You can find that here [https://docs.smods.dev](https://docs.smods.dev).

To distribute this release easily, you can use [https://release.smods.dev](https://release.smods.dev) or [https://download.smods.dev](https://download.smods.dev)
